Stop 1 · Open source

Planet fl_chart

fl_chart is a chart library for Flutter. I open-sourced it in 2019 and I still look after it in my spare time. It draws line, bar, pie, scatter, radar and candlestick charts on every platform Flutter runs on.

107 releases since 2019. The latest is 1.3.1, with 150 of 160 pub points.

Stop 3 · The pilot

Iman Khoshabi

I build mobile apps for a living. I started with native Android in Kotlin and Java, and these days I mostly write Flutter. I have been doing it for more than 10 years, on maps, social, shopping and fintech products.

I am picky about small UI details, and I like code that is clean without being over-engineered. When I am not shipping apps, I make games with Flame, Godot, Cocos Creator and Babylon.js.
