iman_neo

A senior mobile engineer for Flutter and Android. Iman Khoshabi, also known as imaN Neo, builds mobile apps for a living, maintains the fl_chart package and makes small games.

Features

  • Mobile apps end to end, from architecture to release.
  • Flutter (Dart) and native Android (Kotlin, Java). Comfortable in both.
  • UI implementation by someone who is picky about details.
  • Clean code that is not over-engineered.
  • Game development on the side, with Flame, Godot, Cocos Creator and Babylon.js.

Getting started

import 'package:iman_neo/iman_neo.dart';

void main() {
  final iman = ImanNeo(location: 'Amsterdam');

  iman.build(mobileApp);   // 10+ years, Flutter and Android
  iman.maintain(flChart);  // open source since 2019
  iman.play(games);        // 24 of them, free in your browser
}
